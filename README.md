# Laporan Praktikum Sistem Komputer

## Deskripsi

Repository ini berisi file praktikum mata kuliah **Sistem Komputer** dengan topik **Representasi Data dan Sistem Bilangan**.

Praktikum membahas dasar representasi data pada komputer, sistem bilangan, konversi bilangan, operasi biner, ASCII, serta penerapannya dalam bidang Informatika.

## Isi File

### 1. LKP Praktikum
`LKP_Praktikum_Representasi_Data_dan_Sistem_Bilangan_Delvian_Permana_Putra_3312601112.docx`

File ini merupakan lembar kerja/panduan praktikum yang menjadi acuan dalam penyusunan laporan.

### 2. Laporan Praktikum Final
`Laporan_Praktikum_A4_Final_Delvian_Permana_Putra_3312601112.docx`

File laporan praktikum versi final dengan ukuran kertas **A4**. Isi laporan mencakup:

- Perhitungan manual
- Hasil verifikasi menggunakan software

- Output akhir praktikum
